Everything in this path works the same way on a Mac or a Windows PC.

## Two approaches

**1. AI site builders (easiest).** Services such as Lovable, Replit and Bolt let you describe a website in a chat and watch it appear in your browser. Free tiers exist; serious use usually costs $20 or more a month. Great for a quick start.

**2. Your own files (more control).** You keep the website's files on your computer, use an AI assistant to write them, and publish for free. This is what the rest of this path teaches, because you own everything and pay nothing.

## Install a code editor

A code editor is like a word processor for website files. **Visual Studio Code** (VS Code) is free and works on Mac and Windows.

1. Go to [code.visualstudio.com](https://code.visualstudio.com) and download the version for your computer.
2. Install it like any other program.
3. Open it. Choose **File › Open Folder** and create a new folder called `my-website` in your Documents folder.

VS Code can also connect to AI coding assistants such as GitHub Copilot, Claude Code or Codex, which can create and edit your files directly. That's optional. Copying and pasting from a regular AI chat works fine to start.

## Know where your files are

Create a folder for your site and keep everything for it inside. Pictures go in a subfolder called `images`. That's the whole filing system.
