There's more than one good way to build a simple website, and some don't need anything installed. Here are four, from simplest to most hands-on. Pick one to start. You can always switch later, because the website files are the same either way.

## 1. AI site builders

Services such as Lovable, Replit and Bolt let you describe a website in a chat and watch it appear in your browser. Free tiers exist; serious use usually costs $20 or more a month. The catch is that your site lives inside their service, which can make it harder to move later.

## 2. Build in a regular AI chat (no install)

The AI assistant you already use can write a web page and show it to you right in the chat. In **Claude** this is called an artifact; **ChatGPT** and **Gemini** call their version Canvas. It works in a web browser on any computer, and in the phone and tablet apps.

1. Ask for a page, using the prompt in the next lesson.
2. A live preview appears next to (or below) the chat. Ask for changes in plain English and watch the preview update.
3. When you like it, use the **Download** or **Copy** button to save it as a file called `index.html` in your `my-website` folder.

This is a lovely way to try ideas, even from the couch on an iPad. Saving and organizing files is easier on a computer, so many people finish there. Button names change often; if you can't find one, ask the assistant, "How do I download this page as a file?"

## 3. A coding agent in the cloud

Coding agents can create and edit all of your site's files for you, on a computer in the cloud rather than yours. **Claude Code on the web** (at claude.ai/code, or the Code section of the Claude phone app) is one example. OpenAI's **Codex** and GitHub's **Copilot coding agent** work in a similar way.

What to know before choosing this:

- You need a free **GitHub** account (lesson 5 shows how to make one) and usually a **paid AI plan**, often around $20 a month.
- It's the most "hands-off" option: you describe, it builds, you review. It can work while you do something else.
- You still approve every change before it goes live. Read what it says it did, and look at the result on your phone.

## 4. A free code editor on your computer (most control)

A code editor is like a word processor for website files. **Visual Studio Code** (VS Code) is free and works on Mac and Windows.

1. Go to [code.visualstudio.com](https://code.visualstudio.com) and download the version for your computer.
2. Install it like any other program.
3. Open it. Choose **File › Open Folder** and create a new folder called `my-website` in your Documents folder.

You paste in what your AI assistant writes, save, and open the file in your browser. VS Code can also connect to AI coding agents (such as GitHub Copilot, Claude Code or Codex) that edit the files directly, but copy and paste works fine to start.

## Which should I pick?

- **Just curious?** Start with option 2. It's free, and you'll see a page in minutes.
- **Want to own and publish a small site for free?** Options 2 and 4 together: build in a chat, keep the files in a folder, publish in lesson 5. The rest of this path is written this way.
- **Already have a paid AI plan, or prefer working from a phone or tablet?** Option 3 is worth a try.

## Know where your files are

Whichever you choose, keep one folder for your site with everything inside. Pictures go in a subfolder called `images`. That's the whole filing system.
