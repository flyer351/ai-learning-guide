Web pages are written in **HTML** (the content) and **CSS** (the look). You don't need to learn either to start. Your AI assistant writes them, and you'll gradually recognize the patterns.

## Ask for your home page

<div class="try">

**Try it now.** Use your plan from lesson 1:

> I'm a beginner building a simple static website about [topic], for [audience]. Write a complete index.html home page with the CSS included in the same file. Include: a header with the site name "[name]", a short welcome paragraph, a section with three cards linking to pages called projects.html, stories.html and about.html, and a simple footer. Make it look clean and calm, easy to read on a phone, with large text. No JavaScript, no external fonts, no tracking.

</div>

## Put it on your computer

1. In VS Code, create a new file in your `my-website` folder called `index.html`.
2. Paste in everything the AI wrote and save (Command-S on Mac, Ctrl-S on Windows).
3. Find the file in Finder or File Explorer and double-click it. It opens in your web browser.

That's your website, running on your own computer.

Building in a chat instead (option 2 in the last lesson)? You'll see the page in the preview right away. Use **Download** to save it as `index.html` in your `my-website` folder, then double-click it as in step 3. Using a cloud coding agent (option 3)? Paste the same request into it, and it creates the file for you.

## Make changes

Ask for changes the same way you'd brief a designer:

- "Make the header dark green and the text a bit bigger."
- "Add a photo at the top. The file is images/workshop.jpg."
- "Now write projects.html in the same style, with room for six projects, each with a photo and a short description."

After each change, save and refresh the browser (Command-R or F5).

<div class="warn">

**Good to know.** Ask the AI to keep all pages in the same style by saying "Use the same CSS as index.html." Even better, ask it to move the CSS into a shared file called `style.css` once you have two or three pages.

</div>
