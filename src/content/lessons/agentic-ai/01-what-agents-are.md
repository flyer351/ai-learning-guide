So far, you've used AI that **answers**. You ask, it writes, and you do the work. An **AI agent** goes a step further: you give it a goal, and it **takes actions** to reach it, one step after another.

## A workplace comparison

- An **assistant** is like a knowledgeable colleague you ask questions.
- An **agent** is like a new employee you delegate a task to: "Find three quotes for gutter cleaning and put them in a table." They go off, make calls, take notes, and come back with the result.

Like a new employee, an agent is capable but needs clear instructions, limits on what it may do, and someone checking its work.

## What agents can do today

- **Use websites:** fill in forms, compare prices across sites, find appointment times.
- **Work with files on your computer:** sort a messy downloads folder, rename photos, turn receipts into a spreadsheet.
- **Write and run software:** build an app or website from your description, test it, and fix its own mistakes.
- **Research:** read dozens of web pages and write up a report with sources.

## How they work, briefly

An agent is an AI assistant that has been given **tools**: a web browser it can click in, access to certain folders, or the ability to run programs. It plans a step, takes it, looks at the result, and decides the next step, over and over, until the job is done or it gets stuck and asks you.

**Try it now.** Ask the assistant you've been using:

> What agent or "take action" features do you have right now? Explain each in plain English, and tell me what permissions each one needs.

Features change every few months, so this is the best way to find out what yours can do today.

**The takeaway.** Agents save real time on tedious, multi-step tasks. The trade-off is that you're handing over some control, so the rest of this path is about doing that wisely.
